# IO Insight 2023 · 산업연관분석 대시보드 (V2)

**산업조직론 과제물 1**을 위한 2023년 산업연관분석 웹앱입니다. 한국은행 「2023년 산업연관표(연장표)」 생산자가격 데이터로 **산업별 거래 조회**, **최종수요 충격 시뮬레이션**, **두 산업 비교**, **자동 결과 해설**을 지원합니다.

![IO Insight 대시보드 미리보기](assets/dashboard-preview.png)

## 1. 이전 버전과 달라진 점

| 구분 | 기존 V1 | 새 V2 |
| --- | --- | --- |
| 화면 구성 | 하나의 긴 화면 | 대시보드·데이터 탐색·유발효과 분석·산업 간 비교·분석 안내 (5개 메뉴) |
| 데이터 범위 | 4개 산업분류 · 각 12개 시트 | **동일하게 유지** |
| 시나리오 분석 | 여러 산업의 최종수요 증가 합산 | **동일한 계산 엔진 유지** + 빠른 금액 설정 |
| 산업 간 비교 | 독립적으로 두 차례 계산 | **산업 A/B를 한 번에 비교**하고 그래프 표시 |
| 해석 | 결과 수치·배율 설명 | 생산·부가가치·수입 차이를 **자동 해설** |
| 결과 다운로드 | 시나리오 CSV | 시나리오 CSV + **산업 비교 CSV** |
| 사용성 | 반응형 단일 페이지 | 메뉴별 화면과 모바일 전용 레이아웃 |

계산 엔진 `model.py`, Pyodide 실행 워커 `worker.js`, **4개 원본 Excel은 이전 버전과 동일**합니다. UI를 재설계했으며 산업 간 비교도 기존 `simulate()`를 두 차례 호출하는 방식으로 구현했습니다.

## 2. 실행 방법

1. 화면 왼쪽(모바일에서는 상단)의 **DATA CONNECTION**에서 산업분류를 선택합니다.
2. **Excel 데이터 불러오기** 버튼을 누릅니다. 첫 접속은 Pyodide·numpy·openpyxl 설치 및 12개 시트 읽기 때문에 시간이 걸릴 수 있습니다.
3. 상단/왼쪽 메뉴에서 원하는 페이지로 이동합니다.

| 메뉴 | 사용법 |
| --- | --- |
| 대시보드 | 4개 분류 요약, 예시 분석 결과, 기능별 접근 |
| 데이터 탐색 | 시트 선택 → 산업명·코드 검색 → 행·열별 거래값/계수 확인 |
| 유발효과 분석 | 산업과 최종수요 증가액(억원) 입력 → 시나리오 추가 → 유발효과 계산 → 산업별 그래프/CSV |
| 산업 간 비교 | 산업 A·B와 각각의 최종수요 증가액(억원) 입력 → 비교하기 → 4개 지표·상위 유발 산업·자동 해설/CSV |
| 분석 방법 안내 | 계산식, 단위, 원자료, 가정과 한계, 행렬 검증 잔차 |

**분류 전환 시:** 새로운 Excel을 불러와야 하며, 이전 분류의 분석 시나리오와 결과는 초기화됩니다.

**인터넷 연결 필수:** Pyodide 파일은 `https://cdn.jsdelivr.net/pyodide/v0.27.7/full/`에서 다운로드합니다. JavaScript 지원 브라우저의 GitHub Pages HTTPS 환경에서 실행하는 것이 일반적입니다.

### 로컬 확인

프로젝트 루트에서 아래 명령어로 정적 서버를 실행합니다.

```sh
python -m http.server 8000
```

`http://localhost:8000/`에 접속합니다. `file://`로 HTML을 직접 여는 방식은 브라우저 보안 정책 때문에 Excel을 로드하지 못할 수 있습니다.

## 3. 계산 원리

산업 간 중간거래를 반영한 **국산품 최종수요 증가의 정태적 파급효과**를 계산합니다.

- **생산유발액:** `Δx = L Δf` , `L = (I − Aᵈ)⁻¹`
- **부가가치유발액:** `Δv = V Δf` , `V = diag(v) L`
- **수입유발액:** `Δm = M Δf` , `M = Aᵐ L`
- **생산유발배율:** `sum(Δx) / sum(Δf)`

`Aᵈ`는 국산투입계수, `Aᵐ`는 수입투입계수, `v`는 직접 부가가치율입니다. 한국은행 Excel의 계수행렬 `L`, `V`, `M`을 읽어 계산하며 행렬 항등식의 최대 절댓값 잔차가 `1e-7` 미만인지 검증합니다.

원본 거래표와 내부 계산의 금액 단위는 **백만원**, 웹앱 입력과 결과는 **억원**입니다. `1억원 = 100백만원`으로 변환합니다. 투입계수와 유발계수는 **무차원**입니다.

### 산업 비교의 정확한 의미

비교 페이지는 A와 B를 **독립 시나리오**로 계산하며, 두 산업의 수요 증가를 **더해 계산하지 않습니다**. 두 산업의 입력 금액이 다를 때 그래프·총액은 실제 설정한 충격을 보여주고, **자동 해설은 최종수요 100억원당 유발액으로 환산**해서 비교합니다. 즉 분석 목적에 따라 총효과와 단위 금액당 효과를 구분해야 합니다.

## 4. 재현 가능한 검증 사례

**원자료:** 한국은행, 「2023년 산업연관표(연장표)」 생산자가격 **통합대분류(33개 부문)**. 각각의 산업에 대해 **국산품 최종수요 100억원 증가**를 가정합니다.

| 지표 | F 건설 | P 교육서비스 | 두 산업 동시 100억원씩 증가 |
| --- | ---: | ---: | ---: |
| 최종수요 증가액 | 100억원 | 100억원 | 200억원 |
| 생산유발액 | **205.84억원** | **156.90억원** | **362.74억원** |
| 부가가치유발액 | 79.61억원 | 90.66억원 | 170.27억원 |
| 수입유발액 | 20.39억원 | 9.34억원 | 29.73억원 |
| 생산유발배율 | 2.0584배 | 1.5690배 | 1.8137배 |

**직접 확인 방법:** `통합대분류` 데이터를 불러오고, **산업 간 비교**에서 A=`F 건설` 100억원, B=`P 교육서비스` 100억원을 선택하면 각 시나리오의 결과를 동시에 확인할 수 있습니다. **유발효과 분석**에서는 두 산업을 각각 추가해 동시 충격의 합산 결과를 확인할 수 있습니다. 표시값은 반올림될 수 있습니다.

**경제학적 해석:** 동일한 충격의 총생산유발액은 건설업에서 더 크지만, 부가가치유발액은 교육서비스에서 더 크게 나타납니다. 총생산유발액에는 중간재 거래가 포함되므로 **GDP 증가액과 같은 개념이 아닙니다**. 이는 2023년 산업구조에 기반한 가상 수요 충격 결과이며, 미래 예측이나 정책 효과의 인과 추정이 아닙니다.

## 5. 파일 구성

```text

data/
```

## 6. GitHub Pages 배포

### 권장: 새로운 저장소를 이용해 V1 보존

1. 기존에 정상 작동하는 `choHyeonTAK` 저장소는 **유지**합니다.
2. GitHub에서 공개 저장소 `io-insight-2023`을 생성합니다.
3. **이 프로젝트 ZIP 파일의 압축을 해제**합니다. ZIP 파일 자체가 아닌 `index.html`, `style.css`, `app.js`, `worker.js`, `model.py`, `README.md`, `.nojekyll`, `assets/`, `data/`를 저장소 **최상위 경로**에 업로드합니다.
4. `Settings → Pages → Deploy from a branch → main → /(root) → Save`로 설정합니다.
5. 예상 주소는 `https://<GitHub 사용자명>.github.io/io-insight-2023/`입니다. GitHub Actions의 Pages 배포가 완료됐는지 확인합니다.

실제 업로드한 GitHub 저장소 이름이 다르면 웹사이트 주소도 달라집니다. 원본 Excel 중 `data/io-2023-basic.xlsx`는 약 12.3MB이므로 업로드 시 파일 처리가 완료됐는지 확인하세요.

### 기존 저장소를 업데이트하는 경우

기존 V1 파일을 **ZIP 다운로드·별도 백업·Git 커밋** 등으로 보존한 후, V2의 같은 이름 파일들을 교체하세요. V1 웹사이트는 V2 배포 후 UI가 달라집니다. `data/`, `model.py`, `worker.js`는 내용상 변경할 필요가 없습니다.

공식 안내: [GitHub Pages](https://docs.github.com/ko/pages), [저장소 파일 관리](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).
