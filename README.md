# IO Insight 2023 — 산업연관분석 웹앱 확장판

**산업조직론 과제물 1 · GitHub 제출용**

2023년 한국은행 산업연관표(연장표)의 생산자가격 투입산출표를 이용한 브라우저 기반 분석 도구입니다. 통합대분류 **33개**, 통합중분류 **83개**, 통합소분류 **165개**, 기본부문 **380개**와 각 12개 원본 시트를 지원합니다.

![첫 화면](assets/dashboard-preview.png)

## 사용 가능한 6개 심화 분석 도구

| 번호 | 도구 | 실제 동작 | 출력 |
| --- | --- | --- | --- |
| 1 | **산업별 파급효과 순위** | 각 산업에 동일한 국산품 최종수요 100억원 충격 적용. 생산·부가가치·수입 유발액 기준 순위와 검색 | 표·그래프·CSV |
| 2 | **산업연관구조 히트맵** | `Aᵈ` 국산투입계수, `Aᵐ` 수입투입계수, 생산유발계수 `L`의 산업 간 관계 시각화 | 선택 가능한 행렬·공급산업 순위 |
| 3 | **산업별 상세 보고서** | 산업 하나를 선택해 생산·부가가치·수입유발효과 및 주요 공급·생산유발 산업 조회 | 브라우저 인쇄·PDF 저장 |
| 4 | **직접·간접효과 분해** | `Δx = Δf + AᵈΔf + (L−I−Aᵈ)Δf`로 직접·1차·2차 이상 산출 분리 | 수치·누적 막대·산업별 CSV |
| 5 | **정책 시나리오 분석** | 동일한 총국산품 최종수요 증가액을 산업 A/B에 100:0, 0:100, 50:50, 사용자 배분으로 나눠 비교 | 4개 시나리오 그래프·표·CSV |
| 6 | **산업연관 네트워크** | 선택 산업을 중심으로 `Aᵈ`의 주요 **공급 산업 → 중심 산업 → 사용 산업** 관계를 나타냄 | 클릭 가능한 연결 그래프·상세 계수·CSV |

**기존 기능**(Excel 자료 조회, 산업별 시뮬레이션, 두 산업 독립 비교, 자동 해설, CSV 다운로드)도 유지했습니다. 네트워크는 **원본 `국산투입계수(Ad)` 행렬**만을 사용하며 무차원 계수를 나타냅니다. 실제 거래액이나 기업 거래 연결망은 아닙니다.

## 분석 방법과 해석

각 산업의 국산품 최종수요 충격 벡터 `Δf`를 정의하고 한국은행에서 제공한 산업별 계수행렬을 사용합니다.

- **생산유발액:** `Δx = L Δf`, `L = (I − Aᵈ)⁻¹`
- **부가가치유발액:** `Δv = V Δf`, `V = diag(v) L`
- **수입유발액:** `Δm = M Δf`, `M = Aᵐ L`
- **직접·간접 분해:** `Δx = Δf + AᵈΔf + (L−I−Aᵈ)Δf`
- **네트워크(국산투입계수):** `Aᵈ[i,j]` = 사용 산업 `j`의 산출 1단위에 필요한 공급 산업 `i`의 국산 중간재 투입계수. 즉 `i → j` 방향입니다.

총생산유발액에는 중간재 거래가 포함되므로 **GDP 증가액과 같지 않습니다**. 모든 시나리오는 2023년 고정계수 기반의 **가상 정태 분석**으로 실제 예산 지출, 정책의 인과효과, 비용편익 및 고용증가량을 예측하지 않습니다. 네트워크에서 공급·사용 방향의 계수는 분모가 서로 다를 수 있어 총 거래금액처럼 더하거나 단순 비교할 수 없습니다.

원본 거래표 단위는 **백만원**이며 웹앱의 충격 입력·유발액 출력은 **억원**입니다 (`1억원 = 100백만원`). 투입·유발계수는 무차원입니다.

### 계산 재현 사례

통합대분류에서 각각 국산품 최종수요 100억원을 증가시킨 경우:

| 지표 | F 건설 | P 교육서비스 |
| --- | ---: | ---: |
| 생산유발액 | **205.84억원** | **156.90억원** |
| 부가가치유발액 | 79.61억원 | 90.66억원 |
| 수입유발액 | 20.39억원 | 9.34억원 |

건설업 100억원 충격의 생산유발액 직접·간접 구성: **직접 100.00억원 + 1차 간접 54.68억원 + 2차 이상 51.16억원 = 총 205.84억원** (각 수치 반올림).

수치는 아래 원본 Excel의 계수행렬을 프로그램으로 계산한 값입니다. 원본 보도자료에 직접 표시된 수치를 인용한 것이 아닙니다.

## 구성

```text
index.html           전체 화면 및 메뉴
style.css            데스크톱/모바일 레이아웃
app.js               UI, 그래프, 표, 다운로드
worker.js            별도 작업 스레드에서 Pyodide 실행
model.py             Excel 읽기, 계수행렬 검증 및 모든 수치 계산
.nojekyll            GitHub Pages 설정
README.md            사용자 안내·계산 방법
VALIDATION.md        수행한 검증과 아직 필요한 검증
UPLOAD_GUIDE.md      실제 저장소 업데이트 방법
assets/              데스크톱·네트워크·모바일 화면 미리보기
[data/ 또는 루트]
  io-2023-large.xlsx
  io-2023-medium.xlsx
  io-2023-small.xlsx
  io-2023-basic.xlsx
```

Python 서버는 필요하지 않습니다. 브라우저가 [Pyodide](https://pyodide.org/en/stable/)를 통해 Python·NumPy·openpyxl을 실행하므로 최초 로딩 때 외부 CDN에 연결할 수 있어야 합니다.

## 검증 상태 및 출처

- 네 분류의 실제 Excel에서 행렬 항등식 오차 기준 `1e−7` 미만, 순위·히트맵·네트워크·직접/간접 분해 및 산업 보고서 계산 통과.
- Chromium에서 **가상 Worker 응답**을 사용한 UI 버튼, 6개 기능 표시, 네트워크 선택·CSV, 390px 모바일 레이아웃 테스트 통과.
- **아직 미검증:** 변경된 V4 파일을 실제 GitHub Pages에 배포한 이후의 Pyodide CDN 연결과 전 기능 실사용 테스트. 실제 사이트에서도 사용자 확인이 필요합니다.
- **원본 Excel 재배포 권한 별도 확인 필요.** 원본 출처를 표기하더라도 GitHub 공개 저장소 재배포 가능 여부가 자동으로 보장되는 것은 아닙니다.
